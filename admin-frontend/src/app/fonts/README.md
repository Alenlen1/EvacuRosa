# Login fonts

- Public Sans: login interface and supporting copy. Source:
  https://github.com/google/fonts/tree/main/ofl/publicsans
  License: `OFL.txt`.
- Bodoni Moda: the “Ready to respond” headline, chosen for its high-contrast
  display serifs as a visual alternative to the supplied Casiome Impera sample.
  Source: https://github.com/google/fonts/tree/main/ofl/bodonimoda
  License: `BodoniModa-OFL.txt`.

Fonts are bundled locally through `next/font/local`.
